# License decision gate — proposed agent authorization conformance RFC

**State:** OPEN — rights-holder and destination-project review required  
**Scope:** [Agent tool authorization conformance proposal](../rfcs/agent-tool-authorization-conformance-proposal.md) and proposed future test fixtures; not the private Anthesis core or accepted Governance Lab contracts.

## Decision to make

The present public repository states that private Anthesis implementation remains closed source and all rights reserved. No general publication/reuse license has been verified for this new RFC. Merely publishing this draft on GitHub is **not** a grant to redistribute or import it into an LF project.

Prior to upstream contribution, the rights holder and project maintainer must:

1. Confirm ownership/permission for original text, figures, example data and any derivative material; identify material copied from other projects.
2. Confirm the intended recipient's document/specification license and contribution mechanism (including any DCO/CLA, patent and trademark terms).
3. Select an explicit, compatible **document/fixture license** for materials being donated, if authorized, without relicensing private Anthesis source, historical accepted contracts or unrelated works.
4. Record an approved scope (specific paths/revisions) and contributor sign-off; document whether a license header or dedicated license file is needed.
5. Get an independent review of third-party attribution and provenance before importing any existing Governance Lab fixtures.
6. Update the RFC metadata and PR description only after the selection is approved.

**Options to evaluate (not decisions):** Apache-2.0 for independently implemented code/test harnesses; CC-BY-4.0 or an upstream-approved specification license for prose. Check compatibility with receiving project; do not assume a single license suits everything.

## Current gate outcome

- Draft can be reviewed and linked in the originating repository as discussion material.
- **No copying, relicensing or upstream pull request authorized** until steps above are completed.
